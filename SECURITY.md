# Security policy

## Reporting a vulnerability

Use **Security → Report a vulnerability** on the repository if it is available. Otherwise, open an issue that asks for a private contact channel, without including details, and wait for that channel before sharing anything.

Include affected versions, expected and observed behavior, impact and a minimal synthetic reproduction. Remove webhook tokens, client secrets, tenant identifiers and original mail.

## Scope

Only the current source line (App and Runbook 3.7.4) is maintained. There is no backport policy, guaranteed response time or commercial SLA.

For safe operation, see [security and data handling](docs/security.md).
